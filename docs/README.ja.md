# Touyingドキュメント執筆ガイド

このディレクトリにはTouyingのドキュメント原稿があります。
ドキュメントはMarkdownで記述され、Webサイト用リポジトリで利用されます。

## 対象範囲

- `docs/en/`：英語のドキュメント原稿。
- `docs/zh/`：中国語のドキュメント原稿。
- `docs/ja/`：日本語のドキュメント原稿（例のコメントやスライドの内容のローカライズを含む。現在の日本語版の翻訳方針については下記を参照）。
- `docs/README.md`：貢献者向けのこのガイド。

## 主な執筆規約

### 1) 実行可能な例には `example` フェンスを使用する

スニペットをドキュメント用ツールで実行可能な例としてレンダリングし、検証することを意図している場合は、情報文字列に `example` を指定したフェンス付きコードブロックを使用します。

例：

````markdown
```example
#import "@preview/touying:0.8.0": *
#import themes.simple: *

#show: simple-theme.with(aspect-ratio: "16-9")

= Title
== First Slide
Hello, Touying!
```
````

実行できないスニペットには `typst`、`md`、`bash` などの通常のフェンスを使用します。

### 2) `>>>` 行は準備専用の前置き行

`example` ブロック内で `>>> ` が先頭に付いた行は、前置き・準備用の内容として使用されます。
通常は、表示されるデモの本体で定型コード全体を繰り返さずに、スニペットの実行に必要なTouyingの共通の初期化コード（インポートとテーマの設定）を挿入するために使用します。

典型的な前置き：

```typst
>>> #import "@preview/touying:0.8.0": *
>>> #import themes.simple: *
>>> #show: simple-theme
```

スニペットの本体が `#slide[...]`、`#pause`、`#meanwhile`、`#only`、`#uncover` などの機能の使用から直接始まる場合は、このパターンを使用してください。

### 3) `<<<` 行は表示向けの補助行

`example` ブロック内では、ドキュメント用ツールによって通常の実行可能な本体の行とは異なる扱いをする必要がある行に `<<< ` を使用します。
このドキュメント群では、主に複数ファイルを扱うチュートリアルのスニペット（例えば `main.typ` の部分）で、例の処理動作を維持しながら説明文の正確さを保つために使用されています。

`<<<` の使用は最小限にとどめ、この区別が必要な場合だけ使用してください。

## ローカライズと公開先のパス

このリポジトリの内容は `touying-typ/touying-typ.github.io` で公開されます。

- 英語のドキュメント（`docs/en/**`）は `docs/**` 以下に配置されます。
- 中国語のドキュメント（`docs/zh/**`）は `i18n/zh/docusaurus-plugin-content-docs/current/**` 以下に配置されます。
- 日本語のドキュメント（`docs/ja/**`）はロケールの原稿として用意されていますが、公開には `ja` ロケールと対応するインポートパスを `touying-typ/touying-typ.github.io` で設定する必要があります。

ドキュメントを更新する際には、可能な限り `en`、`zh`、`ja` の構造と扱うトピックの範囲を一致させてください。

## 貢献者向けチェックリスト

- 実行可能なデモには `example` フェンスを使用します。
- スニペットにTouyingの初期化設定が必要な場合は `>>>` の前置き行を追加します。
- 複数ファイルを扱う場合や、特別な表示・実行動作が必要な場合に限って `<<<` を維持します。
- `en`、`zh`、`ja` の間で見出し構造とフロントマターの一貫性を維持します。
- 例のリンクとパッケージのバージョンを検証します。

## 日本語版固有の翻訳上の注意点

- 英語原文を基準に、文章、具体例、条件、例外、補足を省略せずに翻訳します。
- インラインコード、識別子、パラメーター、ラベル、パッケージのバージョンを原文のまま維持します。
- コード例では自然言語による説明コメントのみを翻訳します。コメントアウトされたコード、`// pause`・`// meanwhile` のような制御用コメント、スライドの見出し・表示文言、実際のコマンド出力は改変しません。
- リンク先や相対パスの整合性を確認します。
- コード例の翻訳後はTypstによるコンパイルとプレビュー画像生成を確認してください。日本語の表示には日本語フォントが必要になる場合があります。
- このリポジトリに日本語訳を追加するだけでは、Webサイトの言語切り替えには表示されません。
