# Touyingドキュメント翻訳・執筆ガイド

このディレクトリにはTouyingのドキュメント原稿があります。原稿はMarkdownで記述し、Webサイト用リポジトリで利用します。

## ディレクトリ構成

- `docs/en/`：英語の原稿
- `docs/zh/`：中国語の原稿
- `docs/ja/`：日本語の原稿
- `docs/README.md`：英語の執筆ガイド

## コード例の規約

実行・検証する例には、通常の `typst` フェンスではなく `example` フェンスを使います。

````markdown
```example
#import "@preview/touying:0.8.0": *
#import themes.simple: *
#show: simple-theme.with(aspect-ratio: "16-9")

= タイトル
== 最初のスライド
こんにちは、Touying！
```
````

`example` 内で `>>> ` から始まる行は、サンプルを実行するための準備コードとして扱われます。たとえば共通のインポートやテーマの初期化に使用します。必要に応じて `<<< ` から始まる行も使えますが、これは主に複数ファイルの例における表示向けの補助行です。特殊な処理が必要な場合だけ使用してください。

実行を想定しないコードは、`typst`、`md`、`bash` など通常のコードフェンスを使用します。

## 翻訳上の注意点

- 英語版と見出しの構造、フロントマター、ページ構成をできる限り一致させます。
- 関数名、パラメーター、ラベル、パッケージのバージョン、実行可能なコード例を不用意に変更しません。
- リンク先や相対パスの整合性を確認します。
- 実行可能な例では `example`、`>>> `、`<<< ` を維持します。
- 変更履歴の古いリリースには未翻訳の本文が残っています。翻訳状態は `docs/ja/changelog.md` の冒頭を確認してください。

## 公開について

英語版はWebサイトリポジトリの `docs/**`、中国語版は `i18n/zh/docusaurus-plugin-content-docs/current/**` に配置されます。日本語版をサイト上で公開するには、`touying-typ/touying-typ.github.io` 側で `ja` ロケールの設定と `docs/ja/**` の取り込み設定が必要です。このリポジトリに翻訳を追加するだけでは、Webサイトの言語切り替えには表示されません。
